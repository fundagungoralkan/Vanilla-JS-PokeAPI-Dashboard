<h1>🎮 Pokedex Guide</h1>

<p>
This project is a <strong>Pokedex Guide Website</strong> that showcases the first 151 Pokémon in a fun and interactive way.
It is built using <strong>HTML</strong>, <strong>CSS</strong>, and <strong>JavaScript</strong>, and features a fully <strong>responsive design</strong> with an animated header.
</p>

<h1>✨ Features</h1>

<p><strong>Responsive Design:</strong> Fully compatible with all devices (mobile, tablet, desktop)</p>
<p><strong>Animated Header:</strong> Full-screen animated particle background using Finisher Header</p>
<p><strong>Live Search:</strong> Filter Pokémon by name in real time</p>
<p><strong>Dynamic Card Rendering:</strong> Pokémon cards generated dynamically with JavaScript</p>
<p><strong>Type-Based Colors:</strong> Each card's background color matches the Pokémon's type</p>
<p><strong>Hover Effects:</strong> Smooth image zoom and opacity transitions on card hover</p>
<p><strong>PokéAPI Integration:</strong> Fetches live Pokémon data from the public PokéAPI</p>

<h1>📚 Technologies Used</h1>

<p>HTML5</p>
<p>CSS3</p>
<p>JavaScript (ES6)</p>
<p>Font Awesome 6</p>
<p>Google Fonts (Sniglet)</p>
<p>Finisher Header (Animated Background)</p>
<p>PokéAPI</p>
